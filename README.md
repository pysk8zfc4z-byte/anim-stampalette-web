# Animation Stampalette （ビルド成果物）

複数のキャラクターが並んだ短い動画を分割し、背景を消して、
LINEアニメーションスタンプ規格のAPNGとして書き出す道具。

**開く: <https://pysk8zfc4z-byte.github.io/anim-stampalette-web/>**

このリポジトリは公開用のビルド出力だけを置いている。ソースと仕様書は別。
手で編集しない。`npm run deploy` で丸ごと入れ替わる。

- 個人使用。課金・広告・アカウント・解析なし
- **外部通信を一切しない。**動画も画像も端末から出ない。
  読み込んだ動画・設定・書き出した結果は、そのブラウザの IndexedDB にしか残らない
- 一度開けばオフラインでも起動する（Service Worker）
